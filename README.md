# نظام النسخ الاحتياطي الشخصي (تطبيقان لأندرويد + Firebase)

نظام لنسخ بياناتك الشخصية من هاتفك احتياطيًا إلى حسابك السحابي مشفّرة، ثم استعراضها وتنزيلها.

| المكوّن | الوصف | معرّف الحزمة |
|---|---|---|
| `backup-app` | التطبيق الأول على الهاتف المصدر: يجمع، يخزّن في Room، ويرفع (WorkManager) | `app.backup.source` |
| `viewer-app` | التطبيق الثاني: أجهزتي، استعراض، حذف، تنزيل (CSV/JSON/TXT/ZIP) | `app.backup.viewer` |
| `core` | مكتبة مشتركة: التشفير، نماذج البيانات، Firestore، واجهة الدخول | — |
| `firebase/` | قواعد Firestore وStorage، الفهارس، واختبارات القواعد على المحاكي | — |

## ما الذي يُنسخ؟
- **سجل المكالمات** (`READ_CALL_LOG`) والرسائل النصية (`READ_SMS`) عبر واجهات أندرويد الرسمية، وبديلهما استيراد ملف يختاره المستخدم.
- **الحافظة**: نصوص يختار المستخدم حفظها فقط (زر «حفظ محتوى الحافظة» أو «مشاركة ← حفظ في النسخ الاحتياطي»). لا مراقبة في الخلفية، وتُرفض النصوص التي تبدو كلمات مرور أو رموز تحقق أو أرقام بطاقات.

## البنية السحابية
```
users/{uid}/meta/crypto                       ملح + نص تحقق من عبارة المرور (لا مفاتيح)
users/{uid}/devices/{deviceId}                name, model, enabled[], lastSyncAt
users/{uid}/devices/{deviceId}/records/{id}   type, ts, iv, data(مشفّر AES-256-GCM), v
```
المعرّف `id` حتمي (SHA-256) فلا تتكرر السجلات حتى لو أُعيد الرفع. `type` و`ts` غير مشفّرين لأجل التصفية والترتيب؛ أرقام الهواتف والنصوص والأسماء مشفّرة.

## التشفير واستعادة المفتاح
مفتاح AES-256 يُشتق من «عبارة مرور التشفير» (PBKDF2-SHA256، 310 ألف تكرار) على الجهاز، ولا تغادره العبارة ولا المفتاح. تُخزَّن نسخة من المفتاح على كل جهاز مغلَّفة بمفتاح Android Keystore. **الاستعادة على جهاز جديد معتمد = تسجيل الدخول بالحساب + إدخال العبارة نفسها.** فقدان العبارة يعني تعذّر فك التشفير نهائيًا.
